MODUL KEGIATAN SEKOLAH - cara pasang
1. Supabase > SQL Editor: jalankan supabase-kegiatan.sql (membuat 2 tabel + bucket privat "bukti").
2. Salin folder ke repo (struktur sama):
   functions/_lib/util.js            (BARU)
   functions/api/ortu-kegiatan.js    (BARU)
   functions/api/admin-kegiatan.js   (BARU)
   src/worker.js                     (DIGANTI - menambah 2 route)
   public/kegiatan.html              (BARU - halaman panitia)
   public/ortu.html                  (DIGANTI - bagian Kegiatan untuk orang tua)
   public/index.html, public/admin.html (DIGANTI - menu/tautan)
3. Deploy. Tidak ada variabel baru: memakai SUPABASE_SERVICE_ROLE_KEY, ADMIN_PIN, ADMIN_SECRET yang sudah ada.

MODUL INFO TERBARU (pengumuman, agenda, surat)
1. Supabase > SQL Editor: jalankan supabase-info.sql (membuat tabel info_sekolah + bucket publik "info").
2. File baru/diganti (struktur sama):
   functions/api/info.js          (BARU - data publik)
   functions/api/admin-info.js    (BARU - khusus admin)
   src/worker.js                  (DIGANTI - menambah 2 route)
   public/info.html               (BARU - halaman publik)
   public/info-admin.html         (BARU - panel admin, PIN yang sama)
   public/index.html              (DIGANTI - menu, tile, footer, cuplikan beranda)
3. Deploy. Tidak ada variabel baru. Admin mengelola lewat /#info-admin (atau tautan "Kelola info" di bawah halaman Info Terbaru).

MENU KEGIATAN (Jurnal Murid, Ekstrakurikuler, Club, Kegiatan Unggulan)
1. Supabase > SQL Editor: jalankan supabase-jurnal.sql (tabel jurnal_murid, bucket privat "jurnal", kolom info_sekolah.jenis_kegiatan).
   JALANKAN SEBELUM DEPLOY: kode admin-info sekarang menyimpan kolom jenis_kegiatan.
2. File baru/diganti:
   functions/api/jurnal.js, murid-jurnal.js, admin-jurnal.js   (BARU)
   functions/api/info.js, admin-info.js, functions/_lib/util.js  (DIGANTI)
   src/worker.js                                               (DIGANTI - menambah 3 route)
   public/jurnal.html, kegiatan-sekolah.html                   (BARU)
   public/info-admin.html, public/index.html                   (DIGANTI)
3. Alur: murid masuk dengan kode akses (sama dengan Pantau Belajar Anak) > kirim jurnal > admin menyetujui di
   Kelola info > tab "Jurnal murid" > tayang di menu Kegiatan > Jurnal Murid.
   Ekskul/Club/Kegiatan Unggulan: di Kelola info, isi kolom "Jenis kegiatan" pada info (kategori disarankan "Berita Kegiatan").

GURU & STAFF OTOMATIS DARI SUPABASE
   functions/api/guru.js (BARU), public/guru.html, public/data-guru.js, public/footer-sekolah.js.
   Cek jenis undangan: buka /api/guru?jenis=1 . Atur manual dengan variabel GURU_JENIS di Cloudflare bila perlu.

GURU & STAFF: JABATAN + AKUN LOGIN OTOMATIS (username + PIN)
1. Supabase > SQL Editor: jalankan supabase-guru.sql (membuat tabel guru_staf, mengisinya dari daftar tamu guru/staf,
   membuat username & PIN otomatis, mengisi jabatan awal). Periksa hasilnya di Table Editor > guru_staf.
2. File baru/diganti (struktur sama):
   functions/api/guru-login.js (BARU), functions/api/guru.js, src/worker.js,
   public/guru.html, public/data-guru.js, public/kelas.html   (DIGANTI)
3. Deploy. Tidak ada variabel wajib baru (memakai SUPABASE_SERVICE_ROLE_KEY).
   Opsional GURU_EMAIL_DOMAIN: bila Supabase menolak email teknis "username@guru.at-taqwa.sch.id" saat membuat akun,
   isi dengan domain asli yang punya MX record.
4. Alur harian:
   - Guru/staf baru: Table Editor > guru_staf > Insert row, isi "nama" (+ jabatan, kelompok, mapel, foto). Username & PIN muncul otomatis.
   - Ubah jabatan/foto/mapel: edit barisnya; halaman Guru & Staff ikut berubah (maks. 1 menit).
   - Login Administrasi Kelas: username + PIN dari kolom username & pin. Akun Supabase dibuat otomatis saat login pertama.
   - Guru lama yang sudah punya akun email: isi auth_user_id di barisnya agar data kelas lamanya tetap terhubung.
   - Murid: halaman Administrasi Kelas menyinkronkan murid (baru, ganti nama, pindah kelas, tidak aktif) dengan database
     setiap halaman dibuka, atau lewat tombol "Sinkronkan Murid". Buku Tamu sudah membaca database setiap dibuka.

MENU PER PERAN + MENU SAMPING (Administrasi Guru dan Staf)
1. Supabase > SQL Editor: jalankan supabase-peran.sql (SETELAH supabase-guru.sql). Membuat kolom peran, tabel kerja
   tiap peran, dan aturan akses (hanya peran yang bersangkutan yang bisa membuka datanya).
2. File baru/diganti: public/modul-staf.js (BARU), public/kelas.html, public/admin.html, public/index.html,
   public/guru.html, functions/api/guru.js (DIGANTI).
3. Peran ditebak otomatis dari jabatan (pustaka -> pustakawan, bendahara/keuangan -> keuangan, surat/sekretar -> persuratan,
   operator -> operator, lainnya -> guru/staf). Ubah di kolom guru_staf.peran atau lewat menu Akun guru & staf (operator).
   Akun Anda sendiri: set peran = 'admin' agar semua menu tampil.
4. Menu: guru (kelas & nilai) | pustakawan (kartu pelajar, ekskul & club, peminjaman buku) | keuangan (kas, laporan, proposal, LPJ)
   | persuratan (surat masuk, surat keluar, agenda) | operator (pekerjaan, akun guru & staf, data murid). Semua punya Profil saya.
5. Halaman Guru & Staff kini hanya menampilkan yang ada di tabel guru_staf (tidak ada nama ganda dari daftar tamu).

KARTU PELAJAR (menu Pustakawan: desain kartu, data dari database, PDF)
1. Supabase > SQL Editor: jalankan supabase-kartu.sql (SETELAH supabase-peran.sql). Membuat tabel murid_profil (NIS, NISN, tempat/tanggal lahir,
   alamat, foto_path; terisi satu baris kosong per murid), tabel kartu_desain, bucket privat "foto-murid", dan aturan akses.
2. File diganti: public/modul-staf.js, public/kelas.html. Tidak ada variabel baru.
3. Admin utama melengkapi data di Table Editor > murid_profil (tanggal_lahir format YYYY-MM-DD). Data baru langsung bisa dipakai pustakawan
   setelah klik "Muat ulang data". Kolom baru (mis. agama) cukup ditambahkan di tabel: otomatis muncul di daftar "Bagian yang tampil di kartu".
   Murid baru di daftar tamu: jalankan ulang bagian 2 di supabase-kartu.sql.
4. Foto (opsional): unggah ke Storage > foto-murid (mis. 3A/budi.jpg), isi kolom foto_path dengan "3A/budi.jpg". Tanpa foto, kotak foto kosong tampil.
5. Pustakawan: atur judul, warna, ukuran huruf, bagian yang tampil + urutannya, lalu "Simpan tampilan" (berlaku untuk semua pustakawan).
   Pilih kelas (atau Semua kelas), centang murid, pilih format (A4 10 kartu/halaman atau 1 kartu/halaman), klik "Unduh PDF".
   Pembuatan PDF memuat pustaka html2canvas & jsPDF dari cdn.jsdelivr.net, jadi perlu internet.
